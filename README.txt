Class 10 Maths - Chapter 8: Statistics & Probability (PWA WebApp)
=================================================================

HOW TO INSTALL VIA BROWSER ADDRESS BAR (PWA):
1. Extract this ZIP folder.
2. Run a local server inside the extracted folder:
   - Windows: double-click run_pwa_localhost.bat
   - Mac/Linux: run `python3 -m http.server 8008`
3. Open http://localhost:8008 in Chrome or Edge.
4. Click the Install icon in the browser Address Bar (or the 'Install App' button in the header).
   (You can also host this folder on GitHub Pages / Netlify / Vercel for instant HTTPS mobile & desktop install.)
